2. Worum es geht

Das Smarthome Dashboard ist eine private Bedienoberfläche für die eigene Home-Assistant-Installation. Es ist nicht öffentlich zugänglich und wird nur vom Verantwortlichen und seinem Haushalt genutzt. Wer sich mit seinem Google-Konto anmeldet, kann im Dashboard seine YouTube-Abos, Playlists und Videos mit „Mag ich“ ansehen und abspielen.

3. Welche Daten verarbeitet werden

Das Dashboard fragt bei Google nur die Berechtigung https://www.googleapis.com/auth/youtube.readonly an, also reinen Lesezugriff. Damit ruft es über die YouTube Data API ab:

  • den Namen des eigenen YouTube-Kanals, um anzuzeigen, wer angemeldet ist,
  • die abonnierten Kanäle,
  • die neuesten Videos dieser Kanäle,
  • die eigenen Playlists und ihre Videos,
  • die Videos mit „Mag ich“.

Das Dashboard verändert nichts am YouTube-Konto. Es abonniert nichts, bewertet nichts, kommentiert nichts, lädt nichts hoch und löscht nichts. E-Mail-Adresse, Kontakte, Verlauf und andere Google-Dienste werden nicht abgefragt.

4. Wo die Daten gespeichert werden

  • Anmeldung: Das Refresh-Token der Google-Anmeldung liegt mit der Client-ID im Benutzerprofil der eigenen Home-Assistant-Installation. Diese läuft auf eigener Hardware im Haushalt.
  • Zugriffstoken: Das kurzlebige Zugriffstoken (etwa eine Stunde gültig) liegt nur im Arbeitsspeicher des Browsers.
  • Zwischenspeicher: Die zuletzt geladenen Listen liegen im lokalen Speicher des Browsers auf dem jeweiligen Gerät, damit sie beim nächsten Öffnen sofort da sind. Das sind Videotitel, Kanalnamen und Vorschaubilder.

Es gibt keinen Server des Betreibers im Internet. Die Daten gehen direkt zwischen dem Browser des Geräts und den Diensten von Google bzw. YouTube hin und her.

5. Keine Weitergabe

Die Daten werden nur für die Anzeige im Dashboard genutzt. Sie werden nicht an Dritte weitergegeben, nicht verkauft, nicht für Werbung verwendet und nicht ausgewertet. Es gibt kein Tracking, keine Analysedienste und keine Cookies des Betreibers.

Die Nutzung und Übertragung der von Google-APIs erhaltenen Daten hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

6. YouTube und Google

Das Dashboard nutzt die YouTube API Services. Für die Wiedergabe bindet es den offiziellen YouTube-Player ein. Dabei gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

7. Zugriff widerrufen und Daten löschen

  • Im Dashboard unter YouTube auf das eigene Konto und dann auf „Abmelden“ tippen. Dann wird der Zugriff bei Google widerrufen. Auch die gespeicherte Anmeldung und der Zwischenspeicher werden gelöscht.
  • Jederzeit unabhängig davon in den Google-Kontoeinstellungen unter Drittanbieter-Apps und -Dienste.
  • Wird der Zugriff widerrufen, kann das Dashboard keine YouTube-Daten mehr abrufen.
