Smarthome Dashboard

Ein privates Dashboard für die eigene Home-Assistant-Installation.

Das Smarthome Dashboard ist eine Bedienoberfläche für das eigene Zuhause. Es läuft innerhalb einer privaten Home-Assistant-Installation und ist nicht öffentlich zugänglich. Es wird ausschließlich vom Betreiber und seinem Haushalt genutzt.

YouTube-Anbindung

Nach der Anmeldung mit einem Google-Konto zeigt das Dashboard auf dem Wandtablet und im Browser:

  • die neuesten Videos der abonnierten Kanäle,
  • die Liste der Abos,
  • die eigenen Playlists,
  • die Videos mit „Mag ich“.

Die Videos werden mit dem offiziellen eingebetteten YouTube-Player abgespielt. Das Dashboard hat nur Lesezugriff (youtube.readonly). Es kann nichts abonnieren, bewerten, kommentieren, hochladen oder löschen.
